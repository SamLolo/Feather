# Helper Scripts & Tools

Here you will find any helper scripts and tools I use to help maintain the modpack and create releases!

Most are batch files and therefore designed to work on __Windows only!__ I have no plans to port these to other platforms.

I will also not be providing any support for using these scripts. They are mostly here for those that are familiar with the technical side of creating modpacks, and should be used with caution.

*If you would like to contribute your own scripts, open a [pull request](https://github.com/SamLolo/Feather/pulls)!*
